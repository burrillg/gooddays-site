# Good Days site

The public Terms of use, Privacy policy and Support pages for the Good Days iPhone app, served by GitHub Pages at https://burrillg.github.io/gooddays-site/.

Plain HTML and one stylesheet: no scripts, no fonts or trackers from other sites. The app links to `/terms/`, `/privacy/` and `/support/` (`src/lib/legal.ts` in the app repo), so keep those paths.
